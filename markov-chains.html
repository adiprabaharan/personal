Markov chains, transition matrices, and gambler's ruin

Working notes · about 8 min read

A lot of probability problems that look different are the same problem in disguise: a system hops between states, and you want to know where it ends up, or how long it takes. Markov chains are the language for that. Gambler's ruin is the cleanest first example, and it's a good test of whether the machinery actually makes sense.

Memorylessness

A sequence of random states X₀, X₁, X₂, … is a Markov chain if the next step depends only on where you are now, not on how you got there.

P(Xₙ₊₁ = j | Xₙ = i, Xₙ₋₁, …, X₀) = P(Xₙ₊₁ = j | Xₙ = i)

The transition matrix

Label the states 1, …, m. Put the probability of going from state i to state j in row i, column j:

Pᵢⱼ = P(Xₙ₊₁ = j | Xₙ = i)

Every entry is non-negative and every row sums to 1, since from state i you have to go somewhere. Two facts make the matrix worth having:

  • The n-step probabilities are the entries of the matrix power Pⁿ, so P(Xₙ = j | X₀ = i) = (Pⁿ)ᵢⱼ. This follows from summing over intermediate states, which is precisely matrix multiplication (the Chapman–Kolmogorov equations).
  • If μ is a row vector of probabilities for where the chain is now, then μP is the distribution one step later.

Gambler's ruin as a chain

You start with £i. Each round you win £1 with probability p, or lose £1 with probability q = 1 − p. You stop when you hit £0 (ruin) or £N (target). The states are 0, 1, …, N, and 0 and N are absorbing: once you're there, you stay. For N = 4 and a fair game (p = ½), the transition matrix is:

First-step analysis

Let hᵢ be the probability of reaching N before 0, starting from i. Condition on the first round. Whatever happens, the chain restarts from the new state, by memorylessness:

Recurrence hᵢ = p·hᵢ₊₁ + q·hᵢ₋₁, with h₀ = 0 and h_N = 1

With p = q = ½ the recurrence becomes hᵢ₊₁ − hᵢ = hᵢ − hᵢ₋₁. Every step has the same size, so hᵢ is linear in i. The boundary conditions h₀ = 0 and h_N = 1 then force:

Fair gamehᵢ = i / N

Your chance of reaching the target is just your starting fraction of it. Starting at £1 with a target of £4 gives ¼.

The unfair game

For p ≠ q, try solutions of the form hᵢ = xⁱ. Substituting gives the characteristic equation p·x² − x + q = 0, which factors as (x − 1)(p·x − q) = 0. The roots are 1 and r = q/p, so hᵢ = A + B·rⁱ, and the boundary conditions fix A and B:

Unfair game, r = q/p hᵢ = (1 − rⁱ) / (1 − r^N)

Sanity check worth doing yourself: let p → ½, so r → 1. The formula becomes 0/0. Apply L'Hôpital's rule (treating r as the variable) and see whether you recover i/N.

How long does it last?

Let Dᵢ be the expected number of rounds until absorption. First-step analysis again, but now each round costs 1:

Dᵢ = 1 + p·Dᵢ₊₁ + q·Dᵢ₋₁, with D₀ = D_N = 0

In the fair case, guess a quadratic. Which one satisfies both boundary conditions?

Check your thinking

Dᵢ = i(N − i). Check: Dᵢ₊₁ + Dᵢ₋₁ − 2Dᵢ = −2, so ½Dᵢ₊₁ + ½Dᵢ₋₁ = Dᵢ − 1, which rearranges to Dᵢ = 1 + ½Dᵢ₊₁ + ½Dᵢ₋₁. It vanishes at 0 and N. Starting in the middle of a long game is where the expected duration is largest.

The general recipe

  • Identify the states, and which are absorbing.
  • Define the quantity you want as a function of the starting state (a probability or an expected time).
  • Condition on the first step to get a recurrence, and write down the boundary conditions at the absorbing states.
  • Solve the recurrence: linear or quadratic guesses for fair walks, geometric ones (rⁱ) for biased walks.

The same recipe handles escape probabilities in the random walk / electric circuit analogy: hᵢ is a harmonic function, meaning it equals the average of its neighbours, exactly like a voltage in a resistor network with fixed potentials at the ends.
